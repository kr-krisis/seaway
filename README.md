# SeaWay

SeaWay is a web application for tracking sea cargo shipments and predicting vessel arrival times.

The project aims to make shipping information easier to understand by showing vessel locations, voyage updates, and estimated arrival times in one place.

## Features

- **Vessel Tracking** — view vessel locations on a map using AIS data.
- **Voyage Timeline** — follow important events during a voyage.
- **ETA Prediction** — estimate vessel arrival times using machine learning.
- **Delay Prediction** — estimate the probability of shipment delays.

## Technologies

- **Backend:** Python, FastAPI
- **Database:** PostgreSQL, PostGIS
- **Frontend:** JavaScript, MapLibre
- **Machine Learning:** XGBoost or LightGBM
- **Data Source:** AIS data
